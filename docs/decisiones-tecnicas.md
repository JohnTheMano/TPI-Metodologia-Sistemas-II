# Registro de decisiones técnicas

## Proyecto
Sistema de Gestión de Solicitudes Académicas

## Objetivo
Registrar las decisiones técnicas tomadas durante el desarrollo del Trabajo Práctico Integrador de Metodología de Sistemas II.

## Registro de decisiones

### DT-001 - Conservación de la versión inicial

**Decisión:** Conservar la versión original del sistema sin modificaciones.

**Justificación:** Es necesario disponer de una versión base que permita comparar el estado inicial con el resultado obtenido después de aplicar los refactorings.

**Evidencia:** Tag de Git `estado-inicial`.

**Estado:** Aplicada.

### DT-002 - Organización de la documentación

**Decisión:** Crear una carpeta `docs` dentro del repositorio.

**Justificación:** Centralizar las evidencias, el checklist de revisión de código y las decisiones técnicas del proyecto.

**Estado:** Aplicada.
